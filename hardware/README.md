# Hardware

This directory will contain schematics, PCB designs, and enclosure files.

## Planned Contents

- `schematics/` — KiCad schematics for main controller and zone boards
- `pcb/` — PCB layouts (when we move from breadboard to permanent boards)
- `enclosures/` — 3D print files for controller and zone board enclosures
- `wiring/` — Wiring diagrams and cable routing guides

## Current Status

Hardware design is specified in [`docs/project-specification.md`](../docs/project-specification.md). Physical schematics will be added as the project progresses from breadboard prototyping to permanent installation.
